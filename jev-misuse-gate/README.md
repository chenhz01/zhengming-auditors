# JVG v1.0 — Jev 禁区闸（Jev Misuse Gate）

> **一句话命题**：Jev 生态里所有工具都在解决「怎么用得更好」，
> **没有一处把「哪里不该用」变成代码里的红灯**。厂商不会做（等于劝退），社区工具都在做加法，
> 于是**禁区只在文档里，不在 CI 里**。

---

## 1. 它拦什么

Jev（TypeSafe AI 的 System One 决策模型）不生成文字，只返回 Noul / Choice / Score 三种类型化答案。
它有三个**官方自承的短板**（见第 3 节判据表）。这三个短板不该靠读文档记住，该在 CI 里变成红灯。

| 档 | 拦什么 | 依据 |
|---|---|---|
| `math` | 调用点上下文在做数数 / 精确算术 / 日期推算 / 金额发票对账 | TypeSafe 官方文档自查 |
| `chinese` | 上下文有中文且在做细粒度分类判定 | 官方文档：以英文语料为主训练，中文分类准确率下滑 |
| `irreversible` | 调用点上下文有删除 / 退款 / 转账 / 支付 / 权限 | 官方文档 + 三方实测：不可逆动作需极高阈值或人工 |
| `coarse_unit` | 整段落 / 整页一次喂进去 | 实测：段落级判成 other 且置信 0.54；逐句问则判对，置信 1.00 |

**第二杠杆**：Arize 用 23,325 条判定（RAGTruth + SummEval）跑出「默认 0.5 阈值下 Jev 比 Claude Opus 5 差 7 个点，
调优阈值后追平 87%」——**决策阈值这个杠杆比选哪个模型更大**。JVG 不替你调阈值，但把「你要调」这件事摆在调用点前面。

## 3. 判据口径（全部可指源，不是拍脑袋）

- **math** — TypeSafe 官方自查：数数 / 精确算术 / 日期推算 / 多跳推理表现极差，**禁用于金融结算**。
- **chinese** — 官方文档明示以英文语料为主训练，中文细粒度分类准确率下滑。
- **irreversible** — 官方文档要求支付 / 删除 / 权限走极高阈值或人工确认；提示词注入风险仍在。
- **coarse_unit** — 长段落整块问会把内容判成 `other` 且低置信；逐句问则判对。

口径先钉死（§S3.5 第 5 条）：
- 扫描范围：**仅代码文件**（`.py/.ts/.tsx/.js/.jsx/.mjs/.cjs/.go/.rs/.sh`）。文档不参与判定。
- `CALL_SITE_RE` 只认**动词级**三种真调用（见第 4 节）。
- `peak_zone_hits` = 单个文件单档最大命中数；`zone_peaks[z]` = 该档跨文件最大值。两者不可与 `tally`（跨文件求和）混用。

| 4 | **f08「OK」也是假的** | 文件太短，窗口已覆盖全文，rm 本就在窗口内，只是词表匹配不到 | 重做成同函数内距离 18 行 |
| 5 | **语料 1163 个 0 字节文件** | `open(wb).write(b64decode(...))` 先建文件后写内容，异常被 `except: continue` 吞掉 | 改为先读内容再建文件 + 过零字节自检 |

| 7 | 收紧后仍有假阳性（注释掉的例子、docstring 里的 URL） | 端点串不区分引用与叙述 | `def system_one(` 排除 + 端点要求带引号 |

> #3 #4 是**同一件事的两个面**：一个探针的绿是另一个探针的 bug 撑起来的。
> 词表失效时所有位置探针同时变绿 —— 所以**探针之间会互相掩护**，必须外加距离断言。

**这个 0 不能推广成「Jev 生态没人踩禁区」。** 原因有三条：

   这些形态**不在 `CALL_SITE_RE` 的动词级定义里**，所以业务层的调用根本没被扫到。

⇒ 要证明业务层踩没踩，必须**换源**：采集真实产品仓库里的 Jev 用法。本件没有做，如实标注。

## 6. 用法

```bash
python jvg_cli.py batch <目录>            # 扫描，输出文本摘要
python jvg_cli.py batch <目录> --json     # 扫描，输出 JSON（接 CI）
python verify.py                          # 23 项校验
python selftest.py                        # 5 条喂错数据自检
python make_fixtures.py                   # 重建 8 个 fixture（含位置探针距离断言）
python collect.py                         # 重新采集语料（含 0 字节/0 文件闸门）
```

**CI 接入建议**：把 `jvg_cli.py` 当 pre-commit / CI 步骤，命中即 **fail + 打印上下文**。
JVG 的定位是**提示不是判决**——四档都是宽特征，宁可报了让人看，也不该全自动阻断：
`math` / `irreversible` 两档的关键词（`sum` `count` `total` `delete` `transfer`）在通用代码里很常见。

## 7. 已知限制

- 四档均为**关键词 + 上下文窗口**启发式，无 AST 解析，不做语义理解。
- `chinese` 档的触发条件是「窗口内 CJK ≥ 8 **且** 出现任务词」，会误伤恰好含「判断」二字注释的英文上下文。
- `CONTEXT_LINES = 12` 是拍定的，没有用真实仓库做阈值回归；`jevcal` 有个 `cal` 标定子命令，本件没接。
- 只覆盖 Python / TypeScript 系；`.go` `.rs` 混在 `CODE_EXT` 里但没有对应词表调优。
